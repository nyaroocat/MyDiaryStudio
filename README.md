# My Diary Studio

나만의 다이어리 + 커스텀 화상 키보드 웹 앱 (단일 HTML 파일, 설치 불필요)

## 실행 방법
`MyDiaryStudio_v0.6.html` 파일을 더블클릭해 브라우저에서 여세요.
모든 기록은 브라우저 로컬 저장소에 저장됩니다.

## 주요 기능
- 일기 / 월간·주간 다이어리 / 자유 페이지 / 빠른 메모
- 다이어리 꾸미기 테마 16종 (플랫, 스큐어모피즘, 뉴모피즘, 글래스모피즘, 클레이모피즘, 머티리얼 3, 네오 브루탈리즘, 벤토 그리드, 다크 모드, 리퀴드 글래스, Y2K, 미니멀 등)
- 키보드 스튜디오: 배치 5종, 스타일 19종, 키캡 모양·색상·글로우 세부 설정
- 한글 두벌식 조합 입력 지원 화상 키보드
- 타자 소리 프리셋 17종 (청축·갈축·적축·흑축, 도크, 마블, 알프스, ASMR 5종 등)
  - 키별 개성, 스테레오 패닝, 타격마다 랜덤 변주, 프리셋 미리듣기
- 백업(JSON 내보내기)
